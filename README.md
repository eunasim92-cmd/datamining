### 1. API 키 발급

2. REST API 키 복사
3. 노트북의 `API_KEY` 변수에 입력

```python
API_KEY = 'YOUR_API_KEY'  # 여기에 발급받은 키 입력
```

**VWorld API**
1. [VWorld](https://www.vworld.kr) 접속 후 API 키 발급
2. 노트북의 `vworld_key` 변수에 입력

```python
vworld_key = 'YOUR_API_KEY'  # 여기에 발급받은 키 입력
```

## 결론

> 지하철 접근성(역 거리·유동인구)은 서울시 청소년게임제공업의 생존에 유의미한 영향을 미치지 않았다.

EDA·Kaplan-Meier·Cox 모델 전 단계에서 접근성 변수의 유의성이 일관되게 기각되었으며, 생존과 관련된 주요 변수는 아래와 같다.

| 변수 | 근거 | 비고 |
|------|------|------|
| 인허가연도 | Cox p<0.005, 분류모델 중요도 1위 | 시장 환경 변화·관측 기간을 복합 반영하는 교란변수 가능성 |
| 시설면적 | Cox p<0.005, 분류모델 중요도 2위 | 인허가연도와 교란 관계 존재 — 대형 업소가 오래된 업소와 겹치는 구조 |
| 경쟁업소수 | Cox p=0.01, 분류모델 중요도 3~4위 | 현재 시점 단면 기준으로 과거 경쟁 강도 미반영 |
